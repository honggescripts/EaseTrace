# EaseCopy 易练字帖

> 一款专为幼小衔接设计的智能字帖生成工具，支持汉字描红、古诗文章、多故事合集三种练习模式。无需复杂配置，即可生成高清 PDF 字帖，直接打印使用。

## 📌 项目简介

EaseCopy 易练字帖基于 Python + Pillow 开发，能够将任意汉字列表、文章或小故事自动转换为带有米字格描红线的字帖 PDF。工具内置了科学编排的汉字库、经典古诗和品德故事，同时提供丰富的自定义选项（格子颜色、灰度、纸张尺寸、字体等）。**既可以独立运行（不依赖任何 Web 框架），也可以启动友好的 Web 可视化界面**，满足不同用户的需求。

## ✨ 核心功能特性

### 1. 三种练习模式

| 模式 | 说明 | 适合场景 |
|------|------|----------|
| **基础字帖** | 每个汉字在一行中重复若干次：第一个格子为黑色范字，后续格子为灰色描红字，并附带一行完全空白的练习行。 | 集中攻克单个汉字，适合生字表、偏旁部首专项练习。 |
| **文章字帖** | 输入完整的文章（如古诗、课文），自动按每行最大格子数拆分，每行文本对应一行描红格 + 一行空白格。保留原文换行符。 | 整句、整段临摹，培养书写连贯性和语感。 |
| **多故事字帖** | 将多个故事（用空行分隔）分别从新页开始生成，每页固定填满最大行数，最后一页不足时自动补空白行。 | 制作故事合集字帖，提升阅读兴趣与书写量。 |

### 2. 高度可定制的样式

- **格子布局**：每行格子数（5~20）、格子水平间距、行垂直间距、页边距。
- **颜色控制**：格子边框颜色（支持十六进制）、米字格辅助线（十字虚线 + 对角线）颜色、描红字灰度（0~1，0=纯黑，1=极淡）。
- **纸张与分辨率**：支持 A4 或自定义尺寸（宽×高，毫米），DPI 可调（推荐 300）。
- **字体支持**：自动搜索系统楷体（Windows/macOS/Linux），也可上传 `.ttf` / `.otf` 文件。
- **标题设置**：可自定义每页顶部标题文字，或完全隐藏标题。

### 3. 科学编排的内置示例

为方便快速体验，项目内置了三组高质量示例数据，均遵循幼小衔接阶段的认知规律：

- **基础汉字库（约500字）**  
  按笔画数由少到多、从独体字到合体字、兼顾生活主题（数字、方位、家庭、自然、动物、学校、数学等）排列。前150字为1~5画高频字，后逐步增加复杂度，适合一学年的书写练习。

- **经典古诗22首**  
  选自《小学生必背古诗词75首》，包含《咏鹅》《静夜思》《悯农》《春晓》《登鹳雀楼》《望庐山瀑布》等，每首诗附带作者，段落间用空行分隔，自动保留结构。

- **品德小故事20则**  
  以动物为主角的短篇故事，每个故事约150~300字，主题涵盖劳动、坚持、分享、勇气、友谊、安全教育等，语言亲切，价值观正向。

### 4. 智能分页与排版

- 自动计算每页可容纳的行数（考虑标题高度、页边距、行间距）。
- 文章模式和故事模式中，自动按每行最大格子数拆分行，超长行自动换行。
- 故事模式强制每个故事从新页开始，保证故事独立性。
- 最后一页自动补足空白行，保持版面整齐。

### 5. 两种使用方式

#### 🔹 独立运行（无需任何 Web 框架）
直接运行 `幼小衔接字帖.py`，脚本会自动调用内置示例数据，在**桌面**生成三个 PDF 文件：
- `练字字帖.pdf` —— 基础汉字描红
- `诗歌文章练字字帖.pdf` —— 古诗合集
- `多故事练字字帖.pdf` —— 小故事合集

你也可以修改脚本中的 `CalligraphyConfig` 参数，使用自己的内容生成字帖。

#### 🔹 Web 可视化界面（推荐给非技术用户）
运行 `字帖web.py` 后，自动打开浏览器访问 `http://127.0.0.1:5000`，所有参数通过图形界面调整：
- 实时调整格子颜色、灰度、每行数量等。
- 一键加载内置示例，或粘贴自己的文本。
- 生成前自动预估页数，超过30页会弹出警告。
- 点击按钮即可下载 PDF。

## 🚀 快速开始

### 环境要求
- Python 3.8 或更高版本

### 安装依赖
```bash
# 基础依赖（独立运行必需）
pip install pillow

# Web 版额外需要 Flask
pip install flask
```

### 使用方式一：独立运行
```bash
python 幼小衔接字帖.py
```
等待片刻，打开桌面即可看到生成的 PDF 文件。

### 使用方式二：Web 界面
```bash
python 字帖web.py
```
浏览器会自动打开，按界面提示操作即可。

## ⚙️ 配置参数详解

`CalligraphyConfig` 类支持以下参数（Web 端可直接在界面调整）：

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `char_list` | list | 必填 | 基础模式下的汉字列表（每个汉字单独练习） |
| `gray_factor` | float | 0.5 | 灰度系数 0~1，0=纯黑，1=极淡灰 |
| `cols_per_row` | int | 11 | 每行格子数量（同一行内汉字重复次数） |
| `page_size` | str/tuple | 'A4' | 纸张，'A4' 或自定义 (宽_mm, 高_mm) |
| `dpi` | int | 300 | 输出分辨率 |
| `margin_mm` | int | 12 | 页边距（毫米），上下左右相同 |
| `title` | str | "幼小衔接练字" | 页眉标题，设为 `None` 则不显示 |
| `font_path` | str | None | 字体文件路径，不填则自动搜索系统字体 |
| `border_color` | tuple | (70,175,70) | 格子外框 RGB 颜色 |
| `dash_color` | tuple | (190,190,190) | 辅助线 RGB 颜色 |
| `cell_spacing` | int | 0 | 同一行格子之间的水平间距（像素） |
| `line_spacing` | int | 0 | 行与行之间的垂直间距（像素） |
| `char_font_ratio` | float | 0.7 | 汉字在格子中的相对大小（推荐 0.65~0.75） |

## 💡 常见问题

**Q：生成的 PDF 格子太小/太大怎么办？**  
A：调整 `cols_per_row`（每行格子数）或 `char_font_ratio`（字体比例），也可修改纸张尺寸或边距。

**Q：为什么基础模式下有些字不显示？**  
A：请确保系统有中文字体，或手动上传 `.ttf` 字体文件。脚本会自动搜索常见楷体路径（Windows: `simkai.ttf`，macOS: `PingFang.ttc`，Linux: `wqy-microhei.ttc`）。

**Q：故事模式如何强制每个故事从新页开始？**  
A：在输入的故事文本中，用 **两个以上换行符**（空行）分隔不同故事即可。脚本内部已自动处理。

**Q：能否生成带拼音的字帖？**  
A：当前版本不支持拼音，如需拼音可考虑在文章模式中手动写入带拼音的文本（如“你(nǐ)”），或作为后续扩展功能。

**Q：Web 版生成前提示“超过30页”怎么办？**  
A：这是页数预校验功能，避免意外生成长文档。你可以点击“继续生成”或调整每行格子数/边距来减少页数。
